# Exercise swapping and RP tutorial thumbnails

Swap is available directly in the active logger and beside exercises in the workout preview. The equipment picker keeps the current equipment class selected, including when an older profile equipment list omits it. Similar muscle/movement choices remain the default; “Browse all available exercises” is an explicit manual choice with a target review. Available equipment can still be changed deliberately.

Preview swaps stay local until starting the workout. Active-session swaps save durably, retain completed sets and their IDs/observations, and replace only unfinished working sets. New exercise loads start at zero, with effort unreported; no machine/dumbbell conversions or assumed records are introduced. Future routines and completed history remain unchanged. Swaps invalidate staged preview coaching and any previously reviewed shorter plan. Recovery checks and advanced/linked-sequence safeguards remain; the logger offers access to their existing editor.

The tutorial catalog contains 65 public Renaissance Periodization videos. Links were sourced from RP Strength’s public muscle training guides and checked against YouTube oEmbed author metadata on October 28, 2026. Each catalog entry retains its RP source URL and verification date. This is a curated media mapping, not a copy of RP’s programming recommendations or an endorsement.

Thumbnails appear beside logger headings, exercise navigation, preview/queue names, picker/library choices, the selected substitute and completed recap exercises. The logger thumbnail opens the exercise tutorial sheet; the player loads only after Play. YouTube remains the video/thumbnail host. Lazy images omit the referrer, preserve their layout dimensions and fall back to an exercise icon when offline or unavailable. Exact, equipment-aware aliases cover common imported movement names; unmatched custom variants retain a placeholder instead of an unrelated video. Existing personal video links override defaults and are preserved in backups.

Public source examples: [chest](https://rpstrength.com/blogs/articles/chest-hypertrophy-training-tips), [back](https://rpstrength.com/blogs/articles/back-hypertrophy-training-tips), [biceps](https://rpstrength.com/blogs/articles/bicep-hypertrophy-training-tips), [side delts](https://rpstrength.com/blogs/articles/side-delt-hypertrophy-training-tips). No personal training records or provider credentials were inspected to build the mapping.
