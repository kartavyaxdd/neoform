# Premium workout experience

NEOFORM keeps its five destinations and explicit workout preview. Workout home features the next routine workout, or Resume when a draft exists. Other routine workouts, calendar planning and history remain available below it.

The logger keeps the six aligned set columns, tutorial thumbnail, queue and progression action. The prescription opens Targets; Swap and More hold the secondary tools. Shared sheet navigation retains previous views, scroll and unsaved inputs in one native dialog. Back reveals the previous view and returns focus to its trigger. Numeric rows never animate their position.

Shared light/dark surfaces use DM Sans, blue actions and gold records. Spacing uses 4/8/12/16/24/32px tokens. Controls use 120ms feedback, content 180ms and sheets 240ms, with reduced-motion and transparency/contrast fallbacks. Routine status messages float without inserting content above the logger.

Persistence stays owned by the existing store. UI labels distinguish saving, acknowledged device storage, cloud sync and attention. The device acknowledgement accessor only exposes the existing IndexedDB generation acknowledgement; it adds no persisted state. Sync failures remain visible even when a device copy is safe. Review still saves through the existing durable transaction before celebration.

Editors, Gemini views, recap and poster export load when opened. All generated public code and font assets are included in the versioned offline shell. Deferred view failures have local retry recovery. Audio context setup occurs at idle time; the first timer interaction still unlocks playback, and sounds retain their existing preferences.

Verification covers isolated synthetic Worker/D1 and profile boundaries, nested-sheet Back/input/focus retention, offline first-open editing and durable workout saving, PR/Undo/targets, layouts at 360px/390px/desktop, and set-completion acknowledgement with Chromium at 4× CPU throttling without DOM-trace instrumentation. Physical iPhone/Safari testing is reported separately from browser emulation. No training algorithm, prescription policy, schema migration or personal program rewrite is part of this release.
